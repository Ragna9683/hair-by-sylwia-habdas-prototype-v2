# Hair by Sylwia Habdas · версия 2

Откройте `index.html` в браузере. Страница, шрифты и медиа находятся в этой папке. Для просмотра достаточно браузера.

## Запуск из папки репозитория в PowerShell

~~~powershell
Invoke-Item -LiteralPath ".\index.html"
~~~

Первый экран построен вокруг одного кадра 9:16 на угольном фоне. Ролик запускается один раз без звука, когда появляется в поле зрения. Кнопка ставит его на паузу, продолжает показ и запускает заново. При включённом уменьшенном движении доступен стоп-кадр и ручное воспроизведение.

В O nas крупный портрет открывает историю. За ним идут акцент «20+ lat», широкий план интерьера, история о салоне и заключительные слова Сильвии. Польский текст сохранён целиком и в исходном порядке.
